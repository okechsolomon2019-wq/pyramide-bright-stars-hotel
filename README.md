# Pyramide Bright Stars Hotel

A simple HTML5 and CSS website for Pyramide Bright Stars Hotel, featuring hotel
information, room options, dining, guest services, and reservation contact links.

## Preview

Open `index.html` in a web browser. The site uses local images in the `assets/`
directory and does not require a build step or external packages.

## Project files

- `index.html` — website content and navigation
- `styles.css` — colours, fonts, and horizontal rule styling
- `assets/` — hotel and dining images used on the page

Replace the sample hotel contact details and room rate in `index.html` with
verified information before using the site for real bookings.
